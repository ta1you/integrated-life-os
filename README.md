# 統合版 Life OS

最終更新: 2026-10-05  
状態: React + TypeScript のUI初期版を作成中。ホームと授業詳細を実装。ダミーデータのみで、認証・Firebase連携なし。

## このフォルダについて

このフォルダを、統合版 Life OS の企画・設計・開発メモの中心として使う。目指すのは、学生生活・仕事・個人の予定・プロジェクトについて「今の状況が分かり、次に必要な情報へ進める」個人向けの生活OS。

カレンダーを中心に考えるが、カレンダーを全情報の保管場所にはしない。日付を入口にして、授業・課題・シフト・プロジェクト等の詳細へ移れる方向を検討する。

## ローカル起動

Node.js 20.19+ が必要。

```powershell
npm install
npm run dev
```

Viteが表示するURL（通常は `http://localhost:5173/`）を開く。

## 今回の実装範囲

- ホーム: 今日の予定、次の予定、今日やること、期限が近い課題、進行中プロジェクト、よく使う外部リンク。
- 授業詳細: 授業形式・時間・教室・出席状況、前回／今回／次回の授業メモ、関連課題、授業リンク、授業履歴。
- PCは左サイドバー、スマートフォンは下部ナビゲーション。表示中の画面と選択状態を同期する。
- メモはブラウザーのlocalStorage内だけに保存。予定・課題等はすべてダミーデータ。
- カレンダー、時間割、タスク等の独立画面、Firebase、認証、既存アプリとの連携は未実装。

## 現行アプリ

- Life OS: `../my schedule 2/app/`。予定・カレンダー、収支、メモ等。
- School & Work: `../school-and-work/`。時間割、課題、テスト、シフト等。

どちらも現在利用中の既存アプリで、統合版の参考・調査対象として扱う。

## 最優先の保護ルール

- 既存画面や機能、ルーティングを勝手に変更・削除しない。
- 既存Firebaseデータを変更・削除・移行しない。
- 既存プロジェクトを統合版用に作り変えない。大規模リファクタリングをしない。
- 統合版の資料と試作は、原則このフォルダ内に置き、既存アプリから独立させる。
- 既存ファイルの変更が必要になった場合は、対象・理由・変更内容・影響を先に説明し、了承を得る。
- Firebase接続や既存データの利用は、影響・読み書き範囲・復元方法を整理し、明示的な了承を得るまで行わない。

## 現時点の進め方

今後の機能・画面の追加は、ホームと授業詳細の使い勝手を確認してから進める。既存Life OSとSchool & Work、および既存Firebaseデータは変更しない。
